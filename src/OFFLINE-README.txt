منصة الإرشاد الزراعي السورية — نسخة محلية دون إنترنت

طريقة التشغيل:
1) فك ضغط ملف المنصة المحلي بالكامل إلى مجلد على الحاسوب أو الهاتف.
2) افتح index.html بمتصفح حديث مثل Chrome أو Firefox أو Edge.
3) لا تنقل index.html وحده؛ اترك مجلد assets ومحتوياته إلى جانبه.

تعمل الصفحة الأساسية وحاسباتها ومسار التشخيص دون اتصال. روابط المراجع العلمية تفتح فقط عند توفر الإنترنت. لا تُرسل اختيارات نموذج المحاصيل أو إجابات التشخيص ولا تُحفظ. استخدم المصادر التاريخية/التجريبية كما وُسمت ولا تعتبرها جرعات حالية عامة. اطلب معاينة مهندس زراعي محلي وتحليلاً ممثلاً قبل إضافة الأسمدة أو المبيدات.
