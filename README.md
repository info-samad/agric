# المنصة الاستشارية للزراعة الذكية

موقع عربي ثابت باتجاه RTL، يضم دليل المحاصيل وتغذية النبات، تحذيرات موثقة عن الاستخدام غير الآمن للأسمدة الحيوانية في تربة البيوت المحمية، جداولاً مرجعية للطماطم والخيار، وحاسبات تحليلية. لا يحتاج إلى قاعدة بيانات أو مفتاح API، ولا يتضمن خدمة إرسال استشارات.

## التشغيل

افتح `public/index.html` مباشرة لتصفح الموقع والأدوات دون إنترنت. لتشغيل خادم محلي من جذر المشروع:

```sh
python3 -m http.server 3000 --bind 0.0.0.0 --directory public
```

افتح `http://localhost:3000`. تحتاج روابط المراجع الخارجية إلى اتصال بالإنترنت. نموذج الاستشارة محلي فقط؛ لا يرسل البيانات ولا يحفظها.

## تعديل المحتوى بنفسك

عدّل **المصدر** ثم أعد البناء؛ لا تعدّل `public/index.html` وحده لأنه ملف مولّد. بيانات المحاصيل في `research/crops.json`، وتوصيات السماد الحيواني في `research/organic.json`، وملفات تحليل المنتج والصور في `content/`. خطوات التحرير المباشر من واجهة GitHub موجودة في [دليل تحديث المحتوى](content/دليل-تحديث-المحتوى.md).

لا تضع جرعة تسميد داخل سجل محصول لمجرد معرفة اسمه. استخدم `focus` و`checks` لملاحظات الاستدلال، واربط أي ادعاء بمصدر مناسب عبر `sourceIds`. لا تنقل جدولاً من تربة إلى زراعة دون تربة، ولا تحوّل ppm إلى كغ من منتج تجاري من دون معرفة تحليل المنتج وكفاءة الحقن.

## حاسبة السماد العضوي

تظهر الحاسبة في أدوات المزارع، ويمكن فتحها مباشرة من رابط «احسب كمية الدفعة من تحليلها» في قسم السماد. تدخل هدف عنصر كلي مستقلاً، مساحة الحقل، تحليل الدفعة الحالية، وأساس التحليل والرطوبة عند الحاجة؛ فتخرج كتلة منتج نظرية وتبيّن معها N وP₂O₅ وK₂O المحمّلة. لا تنتج جرعة زراعية ولا تستنتج التركيب من اسم الحيوان ولا تعتبر N الكلي N متاحاً للموسم الأول.

واجهة الحاسبة في `src/farmer-tools-section.html`، والحساب في `public/assets/js/farmer-tools.js`، واختباراتها في `scripts/test_calculators.cjs` و`scripts/test_schedule_tabs.cjs`. لا تغيّر المعادلة دون تحديث اختبارات الأساس الرطب والجاف والرطوبة والتحقق من النتائج.

## البناء والفحص

يتطلب البناء Python 3.10 أو أحدث، دون مكتبات Python إضافية:

```sh
python3 scripts/build_site.py
python3 scripts/check_site.py
npm test
for file in public/assets/js/*.js; do node --check "$file"; done
```

قالب الصفحة في `src/index.template.html`، وقالب الاستشارة في `src/consultation.template.html`. الأدوات في `public/assets/js/` وقسم حاسبات المزارع في `src/farmer-tools-section.html`. يعيد البناء توليد صفحات `public` وبيانات المحاصيل منها.

## النشر على GitHub Pages

ارفع **محتويات الحزمة** إلى جذر المستودع، وليس ملف ZIP وحده. يجب أن تظهر المجلدات `public` و`src` و`scripts` و`research`، ومجلد `.github/workflows` المخفي. من إعدادات المستودع اختر **Settings → Pages → Source → GitHub Actions**. يعمل سير `pages.yml` على الفرعين `main` و`master`، ويبني الملفات ويفحصها ثم ينشر مجلد `public` تلقائياً.

بعد أي commit على فرع النشر، افتح تبويب **Actions** وانتظر نجاح سير **نشر المنصة على GitHub Pages**. إذا عملت commit على فرع آخر، ادمجه إلى `main` أو `master` أولاً. لا حاجة لإعادة رفع الموقع كاملاً عند تغيير ملف محتوى أو صورة.

## الاسم ورمز QR والتواصل

اسم المنصة هو **المنصة الاستشارية للزراعة الذكية**. استُخدم شعار الزراعة النظيفة كعلامة بصرية مرتبطة بموقع المنتج، مع إبقاء اسم منتج السماد منفصلاً عن اسم المنصة. رمز QR المحدّث المرسل محفوظ في `public/assets/images/clean-agri-qr.webp`، وقد أمكن فك ترميزه إلى `https://info-samad.github.io/`. في الصفحة يفتح زر الرمز من الرأس موضع الرمز كبير الحجم، بدلاً من الاعتماد على صورة صغيرة غير قابلة للمسح.

تُقرأ بيانات التواصل من `site.config.json`؛ البريد والهاتف فيه رابطان قابلان للنقر. عنوان نشر هذه المنصة يعتمد إعداد Pages للمستودع، وهو مستقل عن الوجهة الموجودة داخل QR.

## حدود المحتوى الزراعي

الحاسبات تحسب من مدخلات المستخدم ولا تستخرج الجرعة من اسم المحصول أو أعراضه. كمية السماد العضوي الناتجة حساب عكسي لهدف **عنصر كلي** وليس توصية تطبيق أو ضماناً لسلامة المادة. افحص التحليل والنضج وEC ومسببات الأمراض وتراكم الفوسفور وماء الري وراجع مختصاً محلياً قبل التطبيق. لا تُحقن مادة عضوية خام أو شاي روث في التنقيط.
